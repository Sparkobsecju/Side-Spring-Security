# 變更驗證規範

只在修改行為、相依性、路由、頁面或準備交付變更時載入本文件。

## 必要驗證

- 修改 Java、Security 設定、頁面路由或 Maven 相依後，執行 `mvn test`。
- 新增或修改登入、授權、登出、公開路徑或轉址行為時，在 `Ch15ApplicationTests` 補上對應的 MockMvc 測試。
- 修改 HTML 時，確認表單 action、HTTP method、輸入欄位名稱與 Security 設定一致。
- 所有文字與程式變更至少執行 `git diff --check`，排除空白錯誤與衝突標記。

## 文件限定變更

- 只修改 Markdown 或註解且不影響編譯與執行行為時，可以只執行 `git diff --check`。
- 若文件揭露實作與規格不一致，應先修正或明確回報，不可只修改文字掩蓋行為問題。

## 交付前檢查

- 確認 Git 變更範圍只包含本次任務，並保留使用者的其他未提交內容。
- 回報實際執行的測試、結果，以及任何未執行項目的原因。
- Security 或正式環境相關變更必須指出仍存在的風險，例如目前教學原型停用 CSRF。
